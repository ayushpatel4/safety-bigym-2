## 1. What this session did: the P2 SVF re-do (4 collection-vs-deployment bugs)

The SVF filter critic was being **collected/swept on a policy that didn't match
deployment**, so the sweep lied about the operating point. **Root cause: `svf_collect_
dataset.py::_build_live_env` is a hand-built replica of the RoboBase factory
`_create_env` (which the deployment adapter uses), and it had drifted in 4 ways.**
All four are now fixed (committed on `phase3`, with regression tests):

1. **Action de-normalisation** — de-normalise the agent's `[-1,1]` action via the
   agent's **demo-derived** stats, not `env.action_space`. Fix: shared
   `env_adapter.action_stats_from_actions`; `tests/test_action_stats.py`. (commit `41fd93b`)
2. **Action-execution mode** — `_CQNASSnapshotPolicy` must roll out **open-loop
   chunks + the temporal-ensemble blend** (mirror `benchmark.runners.CQNASRunner.step`),
   not receding-horizon `chunk[0]`. `action_sequence=16`, `temporal_ensemble=true`.
   `tests/test_snapshot_policy_execution.py`.
3. **control_frequency** — `_build_live_env` must set `control_frequency =
   CONTROL_FREQUENCY_MAX // demo_down_sample_rate` (= **20 Hz** for saucepan; 25
   physics substeps/step), not the default 500 Hz. The 25× mismatch made the policy
   never complete the task (0% success in collection). `_resolve_demo_down_sample_rate`.
4. **Coworker scenario** — read the coworker params from `cfgs/disruption/
   coworker_train.yaml` (closest 0.60–0.95 m, fast reach 1.3–2.2 s), not the drifted
   `_COWORKER_TRAIN_RANGES` Python preset (loose 0.9–1.4 / 4.5–6.5). `_resolve_coworker_overrides`.

**Validation:** the v3 sweep R=0 (filterless) proximity **0.286 ≈ benchmark row-1
0.296**, and filtered `mean_q ≈ 3` matches sweep — the sweep finally **predicts the
benchmark** (broken since v1). The v1 "31.7%@21.6% knee" and v2 "R=2.50" were
artifacts of the broken collection — **superseded.**

Other fixes this session: collection is **snapshot-source only** (`SOURCES=snapshot`
default — random flails/NaNs at 20 Hz); `MAX_STEPS=1000` (deployment horizon);
finite-guard drops NaN transitions on physics instability (collect + sweep);
per-episode progress logging; `LOG=` knob on launchers; `analyze_svf_sweep.py`
knee-picker; `diagnose_collection_policy.py`.

**Pinned in `safety_bigym/filters/snapshots.py`:** `SVF_FILTERS[saucepan_to_hob] =
checkpoints/svf_coworker_train_g1_0p3_v3.pt`, `SVF_FILTER_THRESHOLD_R = 2.25` (light
zero-velocity backstop; see below — provisional).
